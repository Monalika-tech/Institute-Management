# Institute-Management

# Description: A web app for single-subject (Maths) teachers to manage students, class batches, and fees efficiently.

# Manual management of student records, class batches, and fees is inefficient as student numbers grow. This project offers a digital solution for teachers to track records, fees, and organize students efficiently.

## Features

- Secure teacher login
- Class-wise batch organization (Class 9–12)
- Student CRUD operations
- Individual student profile view
- Monthly fee tracking with payment status
- Dashboard with summary statistics
- Search and filter students

## Project Architecture

- React: Handles UI and user interactions
- Node.js + Express: Handles business logic and APIs
- MongoDB: Stores application data
